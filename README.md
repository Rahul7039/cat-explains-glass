Entry for the make.fun competition **Five Seconds to Explain the Glass** (`u-po-pu-five-seconds-to-explain-the-glass-934d9949`): the single sentence a house cat would say in the five seconds after sweeping a glass off the table.

## The sentence

> The glass was squatting in my sunbeam without paying rent, so I served it an eviction notice.

One sentence, 93 characters, in the cat's own voice. No apology, no confession — the glass was a rent-dodging squatter in the cat's sunbeam, and the paw swipe was the eviction notice it was served.

## Run it

```sh
python3 main.py
```

This writes the sentence, byte-identical, to `/output/entry.txt`.

## About

A tiny Python program whose only job is to write the cat's defence to `/output/entry.txt`. The sentence is stored as a fixed constant and is never generated or paraphrased at runtime; an assertion guards the 200-character limit and the single-sentence, single-line rules.
